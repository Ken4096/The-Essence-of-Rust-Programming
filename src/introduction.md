## 《从本质学 Rust 编程》

### 关于本书
　　一本致力于降低 Rust 语言学习门槛，让 Rust 像普通编程语言一样易学易懂的书籍。书中对核心概念均通过反汇编、源码与实例验证其正确性、探究其本质，再通过示例进行讲解，帮助读者真正理解 Rust 编程。在线阅读链接：[《从本质学 Rust 编程》](https://the-essence-of-rust-programming.pages.dev/)

- **适合读者：** 面向希望学习 Rust 的开发者，包括 Rust 初学者以及希望深入理解 Rust 机制的其他语言开发者。
- **写作风格：** 从本质出发，注重原理与实践结合，以简洁易懂的方式讲解 Rust 核心概念。

### 关于 Rust
　　Rust  是一门高性能和高可靠性的编程语言，广泛应用于操作系统、数据库、网络服务、基础软件等领域。它在保持接近 C/C++ 执行性能的同时，将安全性融入语言设计，通过类型系统、所有权、借用和生命周期等机制，在编译阶段保障内存安全与并发安全， 同时通过零成本抽象兼顾高级语言的表达能力与底层语言的运行效率。

- **内存安全：** C/C++ 通常需要开发者手动管理内存，并由开发者负责保证内存安全；Ja发a、Go 与 Python 等语言引入垃圾回收（GC）机制，由运行时自动完成内存回收；而 Rust 则通过编译器保证内存安全，在编译期利用所有权、借用和生命周期机制检查内存访问关系，无需垃圾回收器，也无需手动管理内存，即可在编译阶段避免常见的内存安全问题。
- **无畏并发：** 通过类型系统、所有权和借用机制约束并发环境下的数据访问关系，在编译期即可发现并阻止绝大部分数据竞争等并发安全问题。相比之下，许多其他编程语言更多依赖开发者识别并手动规避并发风险。掌握 Rust 的并发模型后，即使使用其他语言，也能更加敏锐地识别并发场景中的数据竞争、同步和共享数据访问等潜在风险。
- **零成本抽象：**  支持泛型、Trait 和迭代器等高级特性进行代码抽象，且不会引入额外的运行时开销。编译器会在编译期通过单态化、内联等优化手段消除抽象带来的额外开销，使运行时的执行效率与手写底层代码相当。
- **跨平台：** 支持多种操作系统和处理器架构，如 Windows、Linux、macOS、Android、iOS 以及 x86、ARM、RISC-V 等主流平台与架构。借助统一的工具链实现跨平台编译部署，且无需 GC 或虚拟机等重量级运行时，编译产物即可直接运行。
