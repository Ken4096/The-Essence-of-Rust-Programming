# 《从本质学 Rust 编程》

### 关于本书

　　一本致力于降低 Rust 语言学习门槛，让 Rust 像普通编程语言一样易学易懂，从本质出发帮助读者深入理解 Rust 编程的书籍。在线阅读：[《从本质学 Rust 编程》](https://the-essence-of-rust-programming.pages.dev/)

- **适合读者：** 面向希望学习 Rust 的开发者，包括 Rust 初学者以及希望深入理解 Rust 机制的其他语言开发者。
- **写作风格：** 从本质出发，注重原理与实践结合，以简洁易懂的方式讲解 Rust 核心概念。
- **意见反馈：** 本书所有核心概念均通过反汇编、源码分析和示例验证，但因个人技术水平和表达能力有限，难免存在不足和错误，欢迎大家[指正和交流](https://github.com/Ken4096/The-Essence-of-Rust-Programming/issues)。


###  关于 Rust

　　Rust 是一门现代系统级编程语言，兼顾安全性、高性能与可靠性，可广泛应用于操作系统、数据库、网络服务、嵌入式系统以及 WebAssembly 等领域，尤其适合对性能、安全性和资源控制要求较高的基础软件开发。它在保持接近 C/C++ 执行性能的同时，将安全性融入语言设计，通过类型系统、所有权、借用和生命周期等机制，在编译阶段保障内存安全与并发安全，同时通过零成本抽象兼顾高级语言的表达能力与底层语言的运行效率。

- **内存安全：**  C/C++ 通常需要开发者负责内存管理，Java、Go 与 Python 等语言则通过自动内存管理机制降低内存管理的复杂度，并由运行时负责回收不再使用的内存。Rust 则通过所有权、借用和生命周期机制，在编译期检查内存访问关系，从而在无需依赖垃圾回收的情况下保证安全 Rust 代码的内存安全。
- **并发安全：** 编译期借助类型系统、所有权和借用机制防止数据竞争，无需依赖开发者手动保证共享数据的访问安全。
- **零成本抽象：**  Rust 允许开发者使用泛型、Trait、迭代器等高级语言特性进行抽象，同时保持接近底层语言的运行效率，不会因为代码抽象而产生额外的运行时开销。
